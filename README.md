# [Projet Entraînement SQL (FR)](https://github.com/Ymeh-Git/Entrainement_SQL.git)

Entraînement SQL en Python avec explications, exercice à la main, exercices en Python et un Quizz, le tout orienté Dev IA.

## Prérequis

* Visual Studio Code (VSC) ou IDE similaire
* Git
* Extension VSC - Jupyter
* Python 3.14.6 (version au moment du projet)
* Commentaire, dossiers & fichiers en français
* Variable en anglais

## Pour récupérer le projet

Se diriger dans un répertoire exemple Env/Workspace/Entrainements/

<pre>
cd Env/Workspace/Entrainements/
</pre>

<pre>
git clone https://github.com/Ymeh-Git/Entrainement_SQL.git
cd Entrainement_SQL
code .
</pre>

À partir de là, votre VSC devrait s'ouvrir dans le répertoire d'entraînement SQL

## Compréhension de l'arborescence

J'organise mon projet avec un dossier pour chaque exercice, comprenant deux fichiers .ipynb, un avec l'énoncé et une case vide pour pouvoir y répondre, un autre qui a le corrigé dans ces cases vide.

<pre>
Entrainement_SQL
    |__Exercice_n
    |       |__exercice_n_corrige.ipynb
    |       |__exercice_n.ipynb
    |__Exercice_...
    |       |__...
    |       |__...
    |__README.md
</pre>

## Understanding the tree structure

I organize my project with a folder for each exercise containing two .ipynb files: one with the problem statement and an empty cell for the answer, and another with the solution filled into those empty cells.

<pre>
Entrainement_SQL                            --> Project root
    |__Exercice_n
    |       |__exercice_n_corrige.ipynb     --> Exercise correction
    |       |__exercice_n.ipynb             --> Exercise
    |__Exercice_...
    |       |__...
    |       |__...
    |__README.md                            --> Instructions
</pre>
